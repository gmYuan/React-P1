## 第三部分:主要知识点

### 1. Placement flag 同时对应两种操作

`Placement` 在多节点 Diff 中同时表示两种操作：

- **移动**：节点已存在，但位置需要变化
- **插入**：节点是新增的，首次挂载

对于插入操作，之前对应的 DOM 方法是 `parentNode.appendChild`；现在为了实现移动操作，需要额外支持 `parentNode.insertBefore`。

---

### 2. 查找「目标兄弟 Host 节点」的两个注意点

`parentNode.insertBefore` 需要找到「目标兄弟 Host 节点」作为锚点，有两点需要特别注意：

**① 目标兄弟不一定是 Fiber 的直接兄弟节点**

由于中间可能隔着 FunctionComponent 等非 Host 类型节点，需要向下遍历才能找到真正的 Host 节点：

```jsx
// 情况1：<A/> 的目标兄弟 Host 节点是 B 内部的 <div/>，而不是 <B/> 本身
<A/><B/>
function B() { return <div/>; }

// 情况2：<App/> 内部的 <A/> 的目标兄弟 Host 节点是外层的 <div/>
<App/><div/>
function App() { return <A/>; }
```

**② 不稳定的 Host 节点不能作为「目标兄弟 Host 节点」**

自身带有 `Placement` flag 的节点即将被移动，位置不确定，不能作为 `insertBefore` 的锚点。
