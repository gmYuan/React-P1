## 第二部分:实战步骤

### 步骤 1:完善 childFibers，实现单节点 DOM Diff

**路径:** `packages/react-reconciler/src/childFibers.ts`

**修改内容:**
1. 新增 `deleteRemainingChildren`，从 `currentFirstChild` 开始沿 `sibling` 链逐个调用 `deleteChild`，用于找到可复用节点后一次性清除剩余旧节点
2. `reconcileSingleElement` 从 `if + break work` 标签改为 `while` 循环遍历旧兄弟链，按"key → type"两层匹配：key 同 type 同则复用并删除其余兄弟；key 同 type 不同则删除所有旧节点后创建新节点；key 不同则只删当前旧节点并继续遍历兄弟
3. `reconcileSingleTextNode` 同样从 `if` 改为 `while` 循环：tag 为 HostText 则复用并删除其余兄弟；否则删当前节点继续遍历
