# React Update 流程 - Commit 阶段实现

## 第一部分:顶层鸟瞰

### 背景问题

在完成了 update 流程的 render 阶段（beginWork 和 completeWork）后,需要在 commit 阶段真正执行 DOM 操作。commit 阶段需要解决以下核心问题:

- 如何处理 Update flag 标记的节点更新?
- 如何处理 ChildDeletion flag 标记的节点删除?
- 如何递归遍历被删除的子树并执行清理工作?
- 如何找到子树的根 HostComponent 并移除其 DOM?
- 如何实现文本节点内容的 DOM 更新?

**核心挑战:**
- 需要在 commitMutationEffectsOnFiber 中处理 Update 和 ChildDeletion 两种 flags
- 需要实现 commitDeletion 函数处理删除逻辑
- 需要实现 commitNestedComponent 递归遍历子树
- 需要在 hostConfig 中实现实际的 DOM 操作方法
- 需要正确处理 FunctionComponent、HostComponent、HostText 三种节点类型的删除

### 关键技术栈

| 技术 | 说明 |
|------|------|
| **commitUpdate** | 根据 fiber.tag 执行不同类型节点的更新操作 |
| **commitTextUpdate** | 更新文本节点的 textContent |
| **removeChild** | 从容器中移除子节点的 DOM 操作 |
| **commitNestedComponent** | 递归遍历子树的工具函数,支持自定义回调 |
| **rootHostNode 记录** | 找到被删除子树中第一个宿主节点(HostComponent/HostText) |
| **DFS 遍历** | 深度优先遍历,先向下(child)再向上(return),最后遍历兄弟(sibling) |

## 第二部分:实战步骤

### 步骤 1:实现 commitWork 中的 Update 和 ChildDeletion 处理

**路径:** `packages/react-reconciler/src/commitWork.ts`

**修改内容:**
1. 导入 ChildDeletion 和 Update flags
2. 导入 FunctionComponent workTag
3. 导入 commitUpdate 和 removeChild hostConfig 方法
4. 在 commitMutationEffectsOnFiber 中添加 Update flag 处理
5. 在 commitMutationEffectsOnFiber 中添加 ChildDeletion flag 处理
6. 实现 commitDeletion 函数处理节点删除
7. 实现 commitNestedComponent 递归遍历子树

```diff
  import {
+   ChildDeletion,
    MutationMask,
    NoFlags,
-   Placement
+   Placement,
+   Update
  } from './fiberFlags';
  import { FiberNode, FiberRootNode } from './fiber';
  import {
+   FunctionComponent,
    HostComponent,
    HostRoot,
    HostText
  } from './workTags';
  import {
    Container,
-   appendChildToContainer
+   appendChildToContainer,
+   commitUpdate,
+   removeChild
  } from 'hostConfig';

  const commitMutationEffectsOnFiber = (finishedWork: FiberNode) => {
    const flags = finishedWork.flags;
    
    if ((flags & Placement) !== NoFlags) {
      commitPlacement(finishedWork);
      finishedWork.flags &= ~Placement;
    }
    
    // flags Update
+   if ((flags & Update) !== NoFlags) {
+     commitUpdate(finishedWork);
+     finishedWork.flags &= ~Update;
+   }
    
    // flags ChildDeletion
+   if ((flags & ChildDeletion) !== NoFlags) {
+     const deletions = finishedWork.deletions;
+     if (deletions !== null) {
+       deletions.forEach((childToDelete) => {
+         commitDeletion(childToDelete);
+       });
+     }
+     finishedWork.flags &= ~ChildDeletion;
+   }
  };

+ function commitDeletion(childToDelete: FiberNode) {
+   let rootHostNode: FiberNode | null = null;
+   // 递归遍历子树
+   commitNestedComponent(childToDelete, (unmountFiber) => {
+     switch (unmountFiber.tag) {
+       case HostComponent:
+         if (rootHostNode === null) {
+           rootHostNode = unmountFiber;
+         }
+         // TODO 解绑ref
+         return;
+
+       case HostText:
+         if (rootHostNode === null) {
+           rootHostNode = unmountFiber;
+         }
+         return;
+       case FunctionComponent:
+         // Todo useEffect unmount
+         return;
+       default:
+         if (__DEV__) {
+           console.warn('未实现的 delete 类型', unmountFiber);
+         }
+     }
+   });
+
+   // 移除rootHostNode的DOM
+   if (rootHostNode !== null) {
+     // 找到待删除子树的根节点的 parent DOM
+     const hostParent = getHostParent(childToDelete) as Container;
+     removeChild(rootHostNode, hostParent);
+   }
+
+   childToDelete.return = null;
+   childToDelete.child = null;
+ }

+ function commitNestedComponent(
+   root: FiberNode,
+   onCommitUnmount: (fiber: FiberNode) => void
+ ) {
+   let node = root;
+   while (true) {
+     onCommitUnmount(node);
+
+     // 向下遍历，递
+     if (node.child !== null) {
+       node.child.return = node;
+       node = node.child;
+       continue;
+     }
+     // 终止条件
+     if (node === root) return;
+
+     // 向上遍历，归
+     while (node.sibling === null) {
+       // 终止条件
+       if (node.return == null || node.return == root) return;
+       node = node.return;
+     }
+     node.sibling.return = node.return;
+     node = node.sibling;
+   }
+ }
```

### 步骤 2:实现 hostConfig 中的 DOM 操作方法

**路径:** `packages/react-dom/src/hostConfig.ts`

**修改内容:**
1. 导入 FiberNode、HostText workTag
2. 添加 TextInstance 类型定义
3. 实现 commitUpdate 处理不同类型节点的更新
4. 实现 commitTextUpdate 更新文本内容
5. 实现 removeChild 从容器中移除子节点

```diff
+ import { FiberNode } from 'react-reconciler/src/fiber';
+ import { HostText } from 'react-reconciler/src/workTags';

  export type Container = Element;
  export type Instance = Element;
+ export type TextInstance = Text;

  export const createInstance = (type: string /*, props: any */): Instance => {
    // TODO 处理props
    const element = document.createElement(type);
    return element;
  };

    parent: Instance | Container,
    child: Instance
  ) => {
    parent.appendChild(child);
  };

  export const createTextInstance = (content: string) => {
    return document.createTextNode(content);
  };

  export const appendChildToContainer = appendInitialChild;

+ export const commitUpdate = (fiber: FiberNode) => {
+   switch (fiber.tag) {
+     // case HostComponent:
+     //   return updateFiberProps(fiber.stateNode, fiber.memoizedProps);
+     //
+
+     case HostText:
+       const text = fiber.memoizedProps.content;
+       return commitTextUpdate(fiber.stateNode, text);
+
+     default:
+       if (__DEV__) {
+         console.warn('未实现的 commitUpdate 类型', fiber);
+       }
+       break;
+   }
+ };

+ export const commitTextUpdate = (
+   textInstance: TextInstance,
+   content: string
+ ) => {
+   textInstance.textContent = content;
+ };

+ export const removeChild = (
+   child: Instance | TextInstance,
+   container: Container
+ ) => {
+   container.removeChild(child);
+ };
```
